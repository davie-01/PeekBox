# Sparkle 补丁

`Scripts/build-sparkle.sh` 每次从固定提交的原始源码出发，按文件名顺序应用本目录的 `sparkle-*.patch`。

| 补丁 | 原因 |
| --- | --- |
| `sparkle-keep-bundle-mtime.patch` | Sparkle 安装更新时把新应用包的修改时间改成当前时间，随后立即重开并登记应用。LaunchServices 认为在修改后约 5 分钟内做的登记可能不完整，之后每次经系统启动都会重新登记一次，直到某次启动晚于修改 5 分钟；每次重新登记都会结束 PeekBox 正在运行的预览扩展（从预览点设置后预览变回系统默认）。补丁去掉这一步，新包保留打包时的修改时间，与手动解压安装一致。新包经原子交换放到位，是新的文件节点，系统仍能识别出新版本。 |
