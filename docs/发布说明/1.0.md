## PeekBox 1.0

首个正式版本。在 Finder 中选中文件夹或压缩包按空格，即可展开浏览、拖出所需文件，并直接修改 ZIP。

- 浏览文件夹与 ZIP、7z、RAR、TAR 等压缩包，支持列表、图标、分栏三种视图和检查器。
- 拖出压缩包中的文件或文件夹，只提取所选内容；加密压缩包按提示输入密码。
- 向 ZIP 拖入文件、新建目录、重命名或删除条目；修改前的旧版本移到废纸篓，可放回原处。
- 分卷压缩包（`.zip` + `.z01`、`.part01.rar`）可直接按空格单独预览，包括加密的分卷包。
- 写入期间预览窗口保持可操作；压缩包被修改后预览自动刷新。
- 设置主页会提示其他同时启用的预览扩展，它们可能让 PeekBox 不生效。

## 相对测试版的修复

- 更新时后台服务正在写入，更新后删除或重命名报"后台服务不可用"。
- 预览关闭后后台服务长时间不退出。
- 向压缩包添加大文件时内存占用随文件大小增长。
- 全新用户首次打开时后台服务没有自动启用。
