## PeekBox 1.0.3

- 按空格预览磁盘镜像：支持 DMG（含各种压缩格式）、ISO、UDF 及其中的 HFS+、APFS、FAT 文件系统，文件夹预览中的镜像也可直接展开；加密 DMG 会明确提示暂不支持。
- 镜像中的 App 像 Finder 一样显示图标与总大小，替身显示目标图标；把 App 拖到镜像里的“应用程序”替身上即可安装，同名时可选择替换、跳过或保留两者。
- 从镜像拷出的 App 保留符号链接与扩展属性，代码签名保持完整。
- 从压缩包或镜像拖出、打开、拷贝的文件会继承原文件的下载隔离属性。
- 修复图标视图中图标正中无法放下拖入项目、拖动时原条目闪烁的问题。
- 关于页新增“在 GitHub 上查看”，第三方组件列出 7-Zip。
- 更新应用图标。
