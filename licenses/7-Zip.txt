7-Zip in PeekBox
================

PeekBox ships CSevenZip.framework, built by Scripts/build-7zip.sh from the 7-Zip 26.06 source code
(https://github.com/ip7z/7zip, commit d3296e39e1f1f92c7b41c0c3848e65640428d42d). It is used to read disk images
and file systems (DMG, ISO, UDF, HFS+, APFS, FAT, NTFS, ext, virtual disks and partition maps).

- Only the read-side format handlers and decoders listed in Scripts/build-7zip.sh are compiled.
  The CPP/7zip/Compress/Rar* files (GNU LGPL with the "unRAR license restriction") are NOT included;
  RAR archives are read by XADMaster instead.
- The compiled code is under the GNU LGPL 2.1 or later, except CPP/7zip/Compress/LzfseDecoder.cpp and
  C/ZstdDec.c (BSD 3-clause License) and C/Xxh64.c (BSD 2-clause License). Their notices are reproduced below.
- PeekBox modifies the UDF reader (CPP/7zip/Archive/Udf/UdfIn.h, UdfIn.cpp, UdfHandler.cpp) so that images
  containing symbolic links can be opened. The change is published as
  Packages/PeekCore/SevenZipBridge/patches/udf-symlink.patch, and each modified file carries a notice.
- The framework also contains PeekBox's own bridge code (Packages/PeekCore/SevenZipBridge), licensed under
  the GNU GPL version 3 like the rest of PeekBox.
- The framework is a separate dynamic library in PeekBox.app/Contents/Frameworks and can be replaced with
  a build made from modified 7-Zip sources using Scripts/build-7zip.sh.
